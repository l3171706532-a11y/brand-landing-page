## 📊 推导流程（5个阶段）

### 阶段1：特质提取
- 使用 DeepSeek API 收集艺人信息
- 提取：代表作品、公众形象、行为模式、独特印记、关键事件
- Temperature: 0.7（较为准确）

### 阶段2：关系模型推导
- 从行为模式推导"他/她与世界的关系"
- 强制从具体信息（事件、印记）推导，避免抽象联想
- Temperature: 0.9（高创造性）
- **禁止使用科学术语和具象物体**

### 阶段3：本体模型推导
- 从关系模型深入到"他/她是什么"
- 追问存在本质，而非动作过程
- Temperature: 0.9（高创造性）
- **强制从具体信息提取本体属性**

### 阶段4：视觉原型推导
- 将本体模型转化为几何原理和视觉元素
- 将独特印记（数字、物品、动作、符号）转化为具体视觉形态
- Temperature: 0.9（高创造性）
- **直接转化具体元素，避免抽象隐喻**

### 阶段5：设计语言转译
- 翻译为平面设计专业语言
- 输出：色彩系统、形态特征、设计手法、视觉元素、设计原则
- Temperature: 0.7（较为准确）
- **专业术语（透明度、密度、对比）在此阶段是合理的**

## 🔍 独特性检查

推导完成后自动运行独特性检查：

### 检查内容
- 关系类型是否重复
- 本体核心是否重复
- 视觉原型是否重复
- 科学术语是否重复（仅检查第2-4阶段）

### 科学术语黑名单
物理学：密度、梯度、能量、波、场、频率、振幅、质量、惯性、压强、温度、引力、共振  
生物学：养分、生长、吸收、代谢、细胞、组织  
化学：催化、反应、溶解、结晶、聚合、分解  
常见重复：渗透、凝聚、张力、流动、扩散、收缩、释放、内化、转化、消隐、透明、折射

### 检查结果
- ✅ **[OK] This derivation is unique!** - 推导独特
- ⚠️ **[WARNING] Duplicates found** - 发现重复，列出具体术语

## 🛠️ 维护指南

### 1. 更新禁止词汇列表

如果发现新的重复术语，编辑 `brand_philosophy_engine.py`：

```python
# 找到第2阶段的 system_prompt，在"严格禁止"部分添加新术语
严格禁止：
- 禁止使用科学术语（引力、共振、催化、密度、【新术语】等）
```

同时更新 `uniqueness_checker.py`：

```python
# 在 _extract_key_terms 方法中添加
common_terms = [
    '渗透', '凝聚', '张力', '【新术语】'
]
```

### 2. 调整温度参数

如果推导结果太保守或太随机，调整各阶段的 temperature：

```python
# 在各阶段的 deepseek_client.chat.completions.create() 中
temperature=0.9  # 0.0-1.0，越高越有创造性
```

建议值：
- 阶段1（特质提取）：0.7
- 阶段2-4（哲学推导）：0.9
- 阶段5（设计语言）：0.7

### 3. 修改提示词

如果推导方向不符合预期，编辑各阶段的 `system_prompt` 和 `user_prompt`：

```python
# 在 derive_relationship_model() 函数中
system_prompt = """你是品牌哲学家..."""
user_prompt = f"""基于以下特质，推导关系模型..."""
```

### 4. 查看历史推导结果

所有推导结果保存在 `brand_philosophy_outputs/` 目录：

```bash
# 查看最新的5个结果
ls -lt brand_philosophy_outputs/ | head -5

# 查看某个艺人的所有结果
ls brand_philosophy_outputs/ | grep "张译"
```

### 5. 检查单个结果的独特性

```bash
# 手动检查某个结果文件
py uniqueness_checker.py "brand_philosophy_outputs/张译_20260512_021242.json"
```

## 🎯 方法论核心原则

### 1. 从具体到抽象
- ❌ 不要从抽象概念联想（深邃→深海）
- ✅ 从具体事件、印记推导（7次提名→层层叠加）

### 2. 避免科学框架
- ❌ 不要使用物理/化学/生物术语
- ✅ 使用日常动作词汇（走、踏、嵌入、撞上去）

### 3. 避免具象物体
- ❌ 不要使用容器、镜子、球体、深海等具象隐喻
- ✅ 使用抽象动态和几何原理

### 4. 强制具体转化
- 第2阶段：必须引用至少2个具体信息
- 第3阶段：必须从具体信息提取本体属性
- 第4阶段：必须直接转化具体印记为视觉元素

### 5. 设计语言专业化
- 第5阶段可以使用设计专业术语
- 输出可执行的设计指导（色值、形态、手法）

## 🐛 常见问题

### Q1: JSON解析错误
**错误：** `json.decoder.JSONDecodeError: Invalid control character`

**原因：** DeepSeek返回的JSON包含未转义的控制字符

**解决：** 已在代码中添加错误处理，会自动清理控制字符

### Q2: 推导结果重复
**现象：** 多个艺人使用相同的关系类型或术语

**解决：** 
1. 检查 `uniqueness_checker.py` 是否正常工作
2. 运行时会自动生成排除提示词
3. 如果仍重复，手动调整提示词或重新运行

### Q3: 科学术语过多
**现象：** 推导结果包含大量物理/化学术语

**解决：**
1. 检查禁止词汇列表是否完整
2. 增强第2-4阶段的"强制具体转化"提示
3. 提高具体信息的权重

### Q4: 控制台中文乱码
**现象：** Windows控制台显示中文为乱码

**解决：** 这是Windows编码问题，不影响JSON文件保存，文件内容是正确的
